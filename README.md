# 無法将棋（Shogi: Mutation）

敵駒を撃破してポイントを吸収し、駒の移動範囲や特殊能力をリアルタイムに進化（突然変異）させて戦う新感覚の進化型将棋ゲームです。

スマートフォンおよびPCのブラウザからインストール不要ですぐに対局できます。

---

## 🌟 ゲームの特徴

1. **撃破時「即時進化」システム**
   - 相手の駒を取ると、その駒の持ちポイントをそのまま吸収！
   - 手番を消費せずその場で倒した駒や味方駒を即座に強化できます（余ったポイントは貯金可能）。

2. **周囲5×5（全24マス）の自由進化マトリックス**
   - 駒の周囲1マス（内周8マス）だけでなく、**外周16マス（2マス直進や桂馬ジャンプ）も最初から 1pt で自由に解放可能**！
   - 歩の前方2歩進撃や、銀・金への桂馬ジャンプ追加など自由自在なカスタマイズが楽しめます。
   - ※王将・玉将は神聖なシンボルのため進化不可（全周囲8マス・8pt固定）。

3. **「走り（直進無限：∞）」への覚醒**
   - 同じ直進方向の「1マス目」と「2マス目」を開放した駒は、外周マスから **＋1pt** でその方向を「走り（飛車や角のような無限直進ビーム）」へ覚醒可能！
   - 歩を「前1歩 → 前2歩 → 前ビーム（香車化）」へと大化けさせるロマン溢れる育成が可能です。

4. **天王山（５五）制圧ボーナス**
   - 盤面中央の「５五（天王山）」に駐留していると、自分の手番開始時に **＋1pt のボーナスエネルギー**を獲得（連続上限3回まで）。

5. **サドンデス機能（引き分け 0.0% の完全決着）**
   - **80手〜**: 両軍に毎ターン過熱エネルギー（＋1pt）が供給され、決着が加速。
   - **120手到達**: 盤上＋バンクの「総獲得ポイント数」判定でTKO勝利。同点の場合は**最後に天王山（５五）を制圧していたプレイヤーの勝利**！
